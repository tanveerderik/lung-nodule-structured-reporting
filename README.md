# Lung Nodule Structured Reporting

Private staging repository for the Stage 2 implementation accompanying the structured lung nodule reporting study.

The current repository includes supervised fine-tuning, constrained decoding, normalization, scoring, evaluation, and postprocessing code. The sentence-bank construction and synthetic-report generation scripts were developed on a separate computer and will be added before public release.

Clinical reports, manually corrected references, synthetic training records, predictions, evaluation results, model weights, fine-tuned adapters, and experiment logs are intentionally excluded.
